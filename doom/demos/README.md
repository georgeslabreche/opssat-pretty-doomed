# DOOM Demos

Demo recordings used for the PRETTY DOOMed experiment. Each `.lmp` file is a recorded playthrough that the DOOM engine replays to generate gameplay frames.

## Demo Sources

- **compet-n / SDA archive**: Speed demos from the competitive DOOM community. [archive.org/details/competn](https://archive.org/details/competn)
- **classicdoom.com**: Classic demo recordings. [classicdoom.com/odddemos.htm](http://www.classicdoom.com/odddemos.htm)
- **gl- prefix**: Recorded by Georges Labrèche
